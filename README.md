# 치지직 클린 (Chzzk Clean) v2.0.14 ⚡️

치지직(CHZZK) 방송 시청 시 발생하는 그리드(P2P) 강제, 동영상 광고, 안티 애드블록 팝업을 원천 차단하고 1080p 고화질을 재생해 주는 초경량 크롬 확장프로그램입니다.

---

## 🌟 주요 기능
1. **그리드(P2P) 원천 우회**: 
   - `Chzzk P2P Bypass` 최신 엔진을 탑재하여 네이버 동영상 플러그인 요구 없이 1080p 고화질로 즉시 재생합니다.
2. **동영상 광고 및 팝업 무력화**:
   - GFP 암호화 터널링 광고를 해독하여 광고 구간 없이 본 방송으로 직행합니다.
   - "광고 차단 프로그램을 해제해 주세요" 팝업을 원천 차단합니다.
3. **간편한 원클릭 자동 업데이트**:
   - `update.bat`을 더블클릭하면 최신 버전이 자동으로 동기화됩니다.

---

## 💻 윈도우 사용법 (초간단 ⭐️)

### 1. 첫 설치 방법
1. 저장소 우측 상단 초록색 **[Code] ➔ [Download ZIP]** 클릭 (또는 `git clone`)
2. 압축을 푼 뒤 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **'개발자 모드'** 활성화
4. 좌측 상단 **'압축해제된 확장 프로그램을 로드합니다'** 클릭 ➔ 폴더 내의 **`dist`** 폴더 선택!

### 2. 향후 업데이트 방법
- 폴더 안의 **`update.bat`** 파일을 **더블클릭**하면 3초 만에 최신 버전으로 자동 업데이트되며, 완료 결과가 화면에 표시됩니다!
