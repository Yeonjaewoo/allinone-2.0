# 치지직 클린 (Chzzk Clean) v2.0 ⚡️

치지직(CHZZK) 방송 시청 시 발생하는 광고 차단 경고 및 그리드 설치 유도 팝업을 원천 차단하고, 1080p 고화질을 끊김 없이 재생해 주는 순수 TypeScript 기반의 초경량 크롬 확장프로그램입니다.

---

## 🌟 주요 기능
1. **1080p 고화질 고정 & 그리드(P2P) 우회**: 
   - 치지직 PZP 플레이어의 화질 트랙을 감시하여 Non-P2P 최고 화질(1080p)을 우선 적용합니다.
   - 그리드 프로그램 미설치 시 나타나는 설치 유도 팝업을 원천 차단합니다.
2. **동영상 광고 차단 (안티-애드블록 우회)**:
   - 네이버 광고 서버(`veta.naver.com`)의 OPTIONS 프리플라이트 요청에 200 OK를 반환하여 광고 차단기 감지를 무력화합니다.
   - GFP Video Ad Schedule 및 Waterfall 요청을 빈 광고 응답으로 스텁하여 본 영상으로 즉시 진입합니다.
   - 최신 터널링 엔드포인트(`/seoraksan`) 광고 스케줄을 비활성화합니다.
3. **방해 팝업 자동 감지 및 제거**:
   - 실시간 MutationObserver로 팝업을 감지하여 `display: none` 처리 및 닫기 버튼을 자동 클릭합니다.
   - 팝업으로 인해 일시정지된 영상을 0.1초 만에 자동 재생 복구합니다.
4. **미니멀 다크 모드 팝업 UI**:
   - 기능을 간편하게 On/Off 할 수 있는 현대적인 설정창을 제공합니다.

## 💻 윈도우(Windows) 즉시 사용법 (빌드 명령어 불필요! ⭐️)

**Node.js나 복잡한 명령어 전혀 없이 바로 쓰실 수 있습니다:**

1. 윈도우에서 저장소를 내려받습니다 (또는 ZIP 다운로드):
   ```bash
   git clone https://github.com/Yeonjaewoo/allinone-1.git
   ```
2. Chrome 브라우저 주소창에 `chrome://extensions` 입력
3. 우측 상단 **'개발자 모드'** 토글 켜기
4. 좌측 상단 **'압축해제된 확장 프로그램을 로드합니다'** 클릭
5. 내려받은 폴더 내부의 **`dist`** 폴더를 선택하면 등록 완료! 🎉
   *(치지직 방송에 들어가면 광고 팝업 및 그리드 유도 없이 1080p 고화질로 즉시 재생됩니다)*
